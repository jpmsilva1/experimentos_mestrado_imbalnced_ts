# Shared Datasets

This directory contains download scripts and documentation for datasets used across multiple experiments.

## Usage

Do NOT commit large data files to this directory. Instead:
1. Add a download script (e.g., `download_dataset_name.sh` or `download_dataset_name.py`)
2. Document the dataset below
3. Add the dataset path to `.gitignore`
